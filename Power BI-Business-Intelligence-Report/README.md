# Business Intelligence Report - Power BI

## Overview

Developed an interactive Business Intelligence report using Microsoft Power BI to analyze business performance across multiple functional areas.

The report provides dedicated views for **Finance, Sales, Marketing, Supply Chain, Sales Trends, and Executive-level analysis**. A Home Page provides navigation between the different sections of the report.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Modeling
* Data Visualization
* Interactive Dashboard Design

## Dashboard Views

### Home Page

The Home Page serves as the main navigation screen and provides access to all major sections of the Business Intelligence report.

### Finance View

Provides insights into financial performance and key financial metrics.

### Sales View

Analyzes sales performance, customer performance, product performance, and related business metrics.

### Marketing View

Provides insights into marketing performance and relevant business metrics.

### Supply Chain View

Analyzes supply chain performance and operational metrics.

### Sales Trend

Provides analysis of sales trends over time to understand changes in business performance.

### Executive View

Provides a high-level overview of important business KPIs and performance indicators.

## Key Features

* Interactive Home Page navigation
* Multiple business-specific views
* Interactive filters and slicers
* KPI-based analysis
* Dynamic charts and visualizations
* DAX calculations
