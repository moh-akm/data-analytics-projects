# Business Performance Analysis – Excel

## Overview

Analyzed business data using Microsoft Excel to evaluate customer performance, market performance against targets, profitability, and overall business performance across monthly and yearly timeframes..

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Analysis

## Analysis Performed

* Customer Performance Analysis
* Market Performance vs Target
* Profit & Loss (P&L) Monthly Performance Analysis
* Profit & Loss (P&L) Yearly Performance Analysis
  

## Key Areas Covered

### Customer Performance

Analyzed customer-level sales and performance to identify trends and differences in business contribution.

### Market Performance vs Target

Compared actual market performance against predefined targets to identify performance gaps.

### Profit & Loss Analysis Months Performance

Analyzed performance across months to identify trends and changes over time.

### Profit & Loss Analysis Yearly Performance

Analyzed performance across different years(FY) to identify trends and changes over time.
